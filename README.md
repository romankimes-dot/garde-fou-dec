# Garde-fou DEC (hébergement du complément Word)

Copie publiée du volet du complément Word « Garde-fou DEC » : contrôles de forme de la notice et du mémoire DEC, sans IA. Le texte du document ne quitte pas Word.

Ce dépôt ne contient que du code et des règles, aucune donnée. La source fait foi dans le dépôt privé `dec-memoire` (`scripts/garde-fou/`), recopiée ici par `scripts/garde-fou/publier.sh` : ne pas modifier ces fichiers ici.

Installation dans Word : Accueil, Compléments, « Plus de compléments », « Mes compléments », « Charger mon complément », choisir `manifest.xml`.
